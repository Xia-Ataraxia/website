Bible Search

Korean and English verses, side by side.

Kind Obsidian plugins Language TypeScript License MIT ★ 0 stars updated Sep 2026

Search Bible verses by book, chapter, and range in Korean or English and insert them into a note with a configurable template. Dual-language output, multiple versions, verse caching.

A verse search modal takes a book, chapter, and verse range and inserts the result where the cursor is. Template variables control the layout, so a verse can land as a callout, a quote, or a table row.

Not published to the community directory because of licensing on Bible text. Build locally and copy the plugin into the vault.

Installshell

pnpm build
cp main.js manifest.json "$OBSIDIAN_VAULT_PATH/.obsidian/plugins/obsidian-bible-search/"
