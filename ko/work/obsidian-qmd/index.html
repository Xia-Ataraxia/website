Obsidian QMD

Obsidian을 위한 로컬 의미 검색.

종류 Obsidian 플러그인 언어 TypeScript 라이선스 MIT ★ 3 스타 업데이트 2026.09

Obsidian을 로컬 QMD 데몬에 이어 빠르고 사적인 의미 검색을 제공합니다. 키워드·벡터·하이브리드·고급 모드, 관련 노트 사이드바, 노트가 바뀌면 자동 재색인.

모든 처리는 내 기기 안에서 끝납니다. 플러그인이 PATH에서 QMD 바이너리를 찾고, 컬렉션을 볼트에 맞추고, 이미 떠 있는 데몬에서 답을 받습니다.

관련 노트 뷰는 사이드바에 늘 열려 있고, 검색 모달은 의미로 노트를 찾아 앞뒤 맥락을 보여 주며, 결과를 지금 노트에 위키링크로 넣을 수 있습니다.

만든 사람의 볼트 뒤에서 실제로 돌아가는 검색 계층이자, 에이전트가 볼트에 대해 물을 때 답하는 계층입니다.

설치release

# Requires the qmd daemon: https://github.com/tobi/qmd
# Download main.js, manifest.json, styles.css from the latest release into
.obsidian/plugins/qmd/
