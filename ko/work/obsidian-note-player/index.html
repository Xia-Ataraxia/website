Note Player

노트가 곧 플레이리스트.

종류 Obsidian 플러그인 언어 TypeScript 라이선스 MIT ★ 2 스타 업데이트 2026년 9월

어떤 노트든 플레이리스트가 됩니다. Obsidian 임베드 문법으로 YouTube 링크나 로컬 파일을 넣고, 볼트 안에서 소리만 재생하며, 음악 라이브러리를 지식 곁에 둡니다.

플레이리스트는 그냥 Markdown 노트입니다. URL을 넣고, 내 방식대로 메타데이터를 달고, Obsidian을 떠나지 않은 채 재생합니다. 플레이어는 일부러 소리만 냅니다.

오디오는 yt-dlp로 내려받아 로컬에 캐시하므로 바로 재생되고 오프라인에서도 들립니다. 재생 대기열은 세션이 바뀌어도 남고, 함께 딸린 Bases 뷰가 라이브러리를 정리합니다.

설치release

brew install yt-dlp
# Download main.js, manifest.json, styles.css from the latest release into
.obsidian/plugins/obsidian-note-player/
